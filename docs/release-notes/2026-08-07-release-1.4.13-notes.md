# Curated v1.4.13

Curated v1.4.13 is a focused reliability release for backup workflows, poster presentation, and Windows desktop upgrades. It keeps backup destinations across sessions, generates collision-resistant backup package names, preserves portrait thumbnails when metadata providers return a duplicated wide cover, and prevents stale packaged frontend entry points from surviving an Electron upgrade.

## Highlights

- Persisted the backup directory in Web API settings and restored it after refresh or restart; every new backup receives a fresh timestamped `.curated-backup` filename instead of replacing an existing package.
- Kept empty backup arrays encoded as JSON arrays across the API boundary so backup and maintenance responses remain stable for clients with no entries.
- Preserved a distinct portrait card thumbnail when Metatube returns the same wide image for both detail cover and thumbnail; MovieCard now keeps the batch-selection touch target large while making its visual control compact.
- Added explicit frontend cache policy to the local Go static host: entry HTML and SPA fallback use `no-store`, hashed `/assets/*` use immutable long-lived caching, and other static files revalidate.
- Versioned Electron renderer entry URLs with `curatedDesktopVersion` and made installer upgrades remove only the managed legacy/current `frontend-dist` directories, preventing stale desktop UI bundles without touching user data or configuration.
- Added regression coverage for cache headers, installer cleanup directives, poster selection, persisted backup-directory E2E flow, and date-independent watch-time fixtures.

## GitHub Release Body

Curated v1.4.13 improves backup continuity, poster fidelity, and upgrade-safe desktop packaging.

### What's Changed

- Remember the backup directory in Web API mode and restore it after refresh or restart; each new backup uses a unique timestamped filename.
- Keep empty backup results as stable JSON arrays and preserve the existing confirmation-gated backup verification and preflight flow.
- Prefer a distinct portrait search thumbnail when a metadata detail response duplicates its wide cover, and keep MovieCard batch controls comfortable for touch input.
- Serve packaged entry HTML and SPA fallback with `no-store`, keep hashed assets immutable, and revalidate other static files.
- Add the app version to Electron renderer entry URLs and remove only managed old frontend directories during installer upgrades, so stale UI assets cannot survive while user data remains untouched.
- Add focused backend, frontend, Electron, E2E, and release-tool regression coverage for these behaviors.
