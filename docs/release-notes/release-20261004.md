# Curated 20261004

## GitHub Release Body

This release adds dedicated FC2 browsing and multiple video parts per catalog code, unifies Watch History, and improves AI tag organization. Server provides the updated library interface; Desktop also receives the shared settings-dropdown component update.

### Module updates

| Module | Status | Before | After |
| --- | --- | --- | --- |
| Server | Updated | 1.7.8 | 1.7.9 |
| Desktop | Updated | 0.2.3 | 0.2.4 |

### What's Changed

- Server: browse FC2 titles in their own library while keeping storage pools, tags, actors and movie preferences shared.
- Server: keep multiple files with the same catalog code under one movie and one poster. Import additional parts without recreating the movie; recognize numeric suffixes and attached A/B part names.
- Server: choose video parts in details and during playback, with independent resume progress and capture sources for each file. Details select part 1 by default, and automatic playback advances through the remaining parts before the next movie.
- Server: combine ordinary movies and FC2 in Watch History, retaining recorded parts, resume positions and single or batch history deletion.
- Server: use capsule part selectors, show file counts below catalog codes, and fix layout flicker when returning from details to the library.
- Server: focus AI tag organization on unorganized or outdated movies, show organization coverage, and leave full-library reorganization as an explicit action.
- Server: normalize AI topic proposals, preserve valid existing-label aliases, and skip problematic movies for later manual retry so the rest of the task can finish.
- Desktop: update the dropdown component shared with Desktop connection settings.

### Upgrade Notes

- Install only the components with updates. Existing library data and Desktop connections are retained.
- Server automatically registers each previously indexed movie file and preserves its existing progress and captures. Rescan configured storage directories to discover additional parts that older scans did not retain.
- Both independent components have updates in this batch. The new library features are delivered by Server 1.7.9; Desktop 0.2.4 includes the shared dropdown update.
- Old all-in-one installations require the [Full 1.7.3 migration](https://github.com/yepHiu/Curated/releases/tag/full-v1.7.3) first.
