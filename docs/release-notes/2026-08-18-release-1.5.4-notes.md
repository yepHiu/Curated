# Curated v1.5.4

Curated v1.5.4 is a library-to-player flow release. It turns the current browse list into a player playlist, makes large movie imports resumable, and lets library cards open playback or range-select without extra chrome.

## Highlights

- From the library or an actor page, the current ordered grid becomes a player playlist: previous/next, optional auto-advance at the end of a title, and a sliding nearby-window panel.
- Double-click a library card to play it; single-click still opens details. Batch mode selects the whole card, supports Shift range select, and no longer uses poster checkboxes.
- Large movie imports remember unfinished upload sessions, skip chunks the server already has, and can be continued or abandoned from the Add Movies dialog.
- Import, scan, and folder watch now share one 15-type video whitelist, so files such as `.iso` and `.rmvb` are actually catalogued after import. Both import paths refuse to start when the target volume does not have enough free space.
- Bookmark nested menus sit 8px beside the parent panel, companion naming panels align to the top, and the save action is a compact capsule button.

## GitHub Release Body

Curated v1.5.4 turns the current library or actor grid into a player playlist, and makes large movie imports resumable instead of starting over.

### What's Changed

- Carry the current library or actor browse list into the player as a sliding playlist, with previous/next and optional auto-advance when a title ends.
- Double-click a library card to play it; in batch mode, click the card to select it and hold Shift to select a range.
- Resume large movie imports from unfinished upload sessions, skip chunks already on the server, and continue or abandon them from Add Movies.
- Scan and watch the same 15 video types that import already accepted, including `.iso` and `.rmvb`, and refuse imports when the target volume does not have enough free space.
- Keep bookmark nested menus as separate panels with 8px spacing, top-aligned naming, and a compact capsule save button.
