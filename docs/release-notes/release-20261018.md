# Curated 20261018

### What's Changed

- Server: Generate subtitles with Qwen transcription, translate dialogue, and resume interrupted work from persisted progress. Failed subtitle tasks can restart from the beginning while retaining their task identity.
- Server: Review movie, comic and photo organization in a unified task center. Preview AI titles and credits, confirm selected results, and browse confirmed authors and models as library tags.
- Server: Paginate task history and processing details, expand details inline, and expose clearer provider failure causes. Batch confirmation waits for write capacity instead of dropping work.
- Server: Simplify storage, playback and AI settings, add today's AI usage and selectable history page sizes, and hide books whose storage directories have been removed.
- Server and Desktop: Display generated subtitles in Web and native playback, provide a playback-engine choice, unify playback information, improve responsive controls and native volume dragging, and support screenshot identifiers over LAN HTTP.
- Desktop: Add native playback support on Apple Silicon macOS with a bundled playback engine. Windows packages retain the bundled native player and a separate complete source archive.

### Upgrade Notes

- Install only the components with updates. Existing library data and Desktop connections are retained.
- Old all-in-one installations require the [Full 1.7.3 migration](https://github.com/yepHiu/Curated/releases/tag/full-v1.7.3) first.
