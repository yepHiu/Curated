# Curated v1.5.2

Curated v1.5.2 is a library-browse and operations release. It strengthens filters and Saved Views, retires the standalone tags page, backfills missing actor profiles in the background, and turns the message center into live Now / needs-you awareness.

## Highlights

- Strengthened library filters with dismissible chips, a side-by-side facet picker for user/INFO tags (AND), actors (AND) and studios (OR), richer rating/year/runtime/catalog conditions, and explicit grid sort that Saved Views can persist.
- Retired the sidebar Tags page. Old `/tags` bookmarks and Saved Views with `mode=tags` now open the library with the same `tag=` filters.
- When auto actor-profile scrape is enabled, Curated now also backfills historical actors that still lack both avatar and summary, in bounded batches with a 24-hour failed-attempt cooldown.
- Replaced toast-archive messaging with a policy-driven message center: live Now for in-progress work, needs-you for items that still require action, and notify-only Recent. The red badge counts only needs-you.
- Shared scrape concurrency slots across movie and actor scrapes, skipped duplicate in-flight movie refreshes, and showed the scraped metadata provider on movie details.
- Allowed AND multi-tag filtering in the curated-frames library, hid an empty Continue Watching row, and renamed brand source images to kebab-case roles (`wordmark` / `appicon` / `mark`).
- Moved operational long-form documentation out of the root README into `docs/guide.md`.

## GitHub Release Body

Curated v1.5.2 strengthens library browsing and background operations: richer filters, no separate tags page, missing-actor backfill, and a clearer message center.

### What's Changed

- Filter the library with dismissible chips and a facet picker for tags, actors, and studios, plus rating/year/runtime/catalog conditions and explicit sort that Saved Views can keep.
- Open old Tags bookmarks and `mode=tags` Saved Views in the library instead of a separate tags page; movie tags themselves are unchanged.
- Backfill historical actors that still lack both avatar and summary when auto actor-profile scrape is enabled, in bounded batches with a 24-hour cooldown after failed automatic attempts.
- Split the message center into live Now, needs-you, and notify-only Recent; the red badge counts only items that still need you.
- Share scrape slots across movie and actor work, skip duplicate in-flight movie refreshes, and show the scraped metadata provider on movie details.
- Filter curated frames by multiple tags (AND), hide an empty Continue Watching row, and keep brand source images under kebab-case names.
