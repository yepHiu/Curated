# Curated v1.5.1

Curated v1.5.1 is a media-capture and library-experience release. It adds a complete long-press GIF workflow around curated frames, improves capture feedback and watermarking, and continues simplifying the movie, actor, settings, and player surfaces.

## Highlights

- Added long-press GIF clip capture from the player, including press-time anchoring, live playback timing, maximum-duration enforcement, independent consecutive captures, FFmpeg task generation, progress feedback, and persistence alongside curated frames.
- Added GIF download/export support with the official Curated watermark, clearer completion and error feedback, a 640px default export width, and tighter watermark metadata spacing.
- Improved library navigation and information density: shared-actor movies appear on detail pages, empty related-movie sections stay hidden, actor scroll position is preserved, recommendation actions align with tags, and home/player/settings headings and hints are more concise.
- Added confirmation before refreshing metadata for a single movie and removed the obsolete player curated toolbar action and legacy gamepad-navigation layer.
- Kept the release package workflow reproducible with versioned frontend assets, release Go backend metadata, Electron staging, bundled FFmpeg runtime, portable archive, installer, and manifest.

## GitHub Release Body

Curated v1.5.1 brings a complete GIF capture workflow to curated frames and streamlines the surrounding library experience.

### What's Changed

- Hold the player capture action to record a GIF clip with playback-aware timing, bounded duration, smooth progress, and safe consecutive captures.
- Persist captured GIFs with curated frames and export them with the official Curated watermark, improved download feedback, and a 640px default width.
- Show movies that share an actor on detail pages, keep empty related sections hidden, and preserve actor-library scroll position while browsing.
- Simplify home section headers, player media headings, settings descriptions, theme/comment controls, and recommendation action alignment.
- Confirm single-movie metadata refreshes before starting the operation and remove the obsolete player curated toolbar action and legacy gamepad navigation layer.
