# Curated 20261007

## GitHub Release Body

Windows Desktop now includes Curated's native mpv player, with matching Server playback entry points.

### Module updates

| Module | Status | Before | After |
| --- | --- | --- | --- |
| Server | Updated | 1.7.9 | 1.7.10 |
| Desktop | Updated | 0.2.4 | 0.2.5 |

### What's Changed

- **Windows Desktop:** bundles a pinned mpv engine with the native video host and Curated player UI. Playback uses the current Server login and authenticated HTTP/Range streaming, including when Desktop and Server run on different computers.
- The dedicated player keeps the Windows system title bar, shows the movie code in its caption, and shares round controls, file/part selection, seeking, speed and volume with the Web player. Native playback saves file-specific progress, history and watch time and supports an explicit handoff back to Web.
- Adds static frame and GIF capture to the Server frame library, with preview, progress, cancellation and retry. Success feedback now disappears automatically and sits near the transport controls.
- Expands playback information with video/audio, decoder/drop, transfer and cache metrics plus copy/save actions. Values stay aligned during refresh; playback states use `playing`, `paused` and other English engine states.
- Ships matching engine/library licenses, exact build records and complete offline corresponding sources. Windows production builds fail if the engine, source materials, checksums or required DLLs are missing, and installed-player checks gate publication.
- Fixes startup authentication ordering so no protected library reads start before the PIN status is confirmed, and updates Vue/source-map-js to patch two high-severity dependency advisories.
- **Server/Web:** connects existing playback entries and the sidebar to the Desktop player; replaces scroll-based Home/library switching with explicit navigation and aligns topic organization dialog buttons with the UI conventions.

### Upgrade Notes

- Update **both Server and Desktop** for the native playback entry points, then enable **Settings → Playback → Prefer the Desktop native player** on Windows. No separate mpv download or executable selection is required after installation.
- Existing library data, saved Server connections and per-machine playback preferences are retained. Native playback remains opt-in. macOS and browser playback continue using Web.
- This Windows Desktop package is substantially larger because it includes the complete offline corresponding-source archive. Those materials are under `resources/app/native-player/sources/`; licenses and restoration instructions are in its `licenses/` directory.
- Old all-in-one installations require the [Full 1.7.3 migration](https://github.com/yepHiu/Curated/releases/tag/full-v1.7.3) first.
