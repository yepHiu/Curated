# Curated v1.4.11

Curated v1.4.11 focuses on actor browsing, navigation correctness, packaged desktop reliability, and a few workflow improvements around exporting and live task updates.

## Highlights

- Added a dedicated actor detail route so actor cards and movie-detail actor links open a standalone actor page instead of reusing the generic all-movies filter page.
- Tuned the actor library UI by hiding low-value actor tag chips and making actor cards more useful visually with larger avatars and a tighter grid.
- Fixed detail-to-filter and detail-to-actor navigation return intents so back buttons return to the originating detail page when that is where the journey started.
- Fixed player teardown so hidden picture-in-picture or abandoned player routes do not leave media playing behind the current page.
- Added active movie-library CSV export for easier local review and sharing of the current library view.
- Added server-sent task updates and packaged offline desktop resources to make packaged builds less dependent on external runtime assets.

## GitHub Release Body

Curated v1.4.11 improves actor browsing and tightens several navigation and packaged-desktop edges.

### What's Changed

- Actor cards and movie-detail actor links now open a dedicated actor page, with the actor profile and related films presented as their own focused view.
- Actor cards are easier to scan: avatars are larger, the grid is tighter, and actor tag chips are hidden from the primary actor UI for now.
- Back navigation now respects where you came from. Actor pages opened from movie details return to that detail page, while actor-library entries still return to the actor library.
- Detail-page tag/studio filter journeys keep their original detail return intent.
- Player teardown now stops media cleanly when leaving playback, preventing hidden playback from continuing behind another page.
- Desktop/package reliability is improved with bundled offline runtime resources and live server-sent task updates.
- Active movie-library views can now be exported to CSV.
