# Curated v1.4.12

Curated v1.4.12 is a substantial local-first reliability and personalization release. It adds durable backup and maintenance workflows, reusable library views, explainable recommendation controls, canonical actor merging, personal viewing insights, stronger local security defaults, and several navigation, layout, and playback improvements.

## Highlights

- Added consistent library backup creation, verification, restore preflight, and offline restore tooling, with maintenance controls surfaced in Settings.
- Added audited library path migration and restart-safe resumable upload sessions so long-lived libraries are safer to move and large imports can recover after interruption.
- Added Library Health diagnostics, bounded metadata repair queues, and confirmation-gated cleanup actions with auditable results.
- Added reusable Saved Views for advanced library filters and sorting, persisted in SQLite for Web API mode and local storage for Mock mode.
- Added recommendation explanations and explicit local feedback controls, including not-interested, snooze, and “recommend less” signals that affect subsequent recommendation generation.
- Added canonical actor identity and a preview-first transactional merge workflow covering movies, aliases, tags, links, profile fields, and recommendation feedback.
- Added a lazy-loaded Personal Insights dashboard for local watch time, completion, ratings, and actor/studio/tag breakdowns across selectable date ranges.
- Hardened local access with loopback-first listeners, Origin/Host validation, PIN attempt rate limiting, trusted sessions, protected post-unlock hydration, SQLite foreign-key enforcement, and patched frontend dependencies.
- Refined the Settings maintenance workspace to match the established UI specification, restored History page title spacing, and preserved actor-page return intent through detail and playback round trips.
- Reduced the dynamically loaded HLS player by switching to the light runtime while keeping it outside the initial application dependency closure.

## GitHub Release Body

Curated v1.4.12 is a substantial local-first reliability and personalization release.

### What's Changed

- Back up, verify, preflight, and restore Curated library packages with safer offline maintenance workflows.
- Move library roots through an audited path-migration flow, and resume large upload sessions after interruption or restart.
- Diagnose library integrity from the redesigned Maintenance workspace, queue bounded metadata repairs, and run confirmation-gated cleanup actions.
- Save advanced library filters and sorting as reusable Saved Views. Web API mode persists them in SQLite; Mock mode keeps them locally in the browser.
- Understand and adjust daily recommendations with visible reasons, not-interested actions, snoozes, “recommend less” signals, undo, and centralized feedback management.
- Preview and transactionally merge duplicate actor identities into one canonical actor while preserving aliases and auditing affected data.
- Explore local Personal Insights for watch time, completion, ratings, and actor/studio/tag preferences across 30-day, 90-day, yearly, and all-time ranges.
- Benefit from stronger local defaults: loopback-first networking, Origin/Host checks, PIN rate limiting, trusted sessions, protected hydration, foreign-key enforcement, and patched frontend dependencies.
- Enjoy corrected actor-detail/player back navigation, proper History title spacing, a UI-spec-aligned maintenance page, and a lighter dynamically loaded HLS runtime.
