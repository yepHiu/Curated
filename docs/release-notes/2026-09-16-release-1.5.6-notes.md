# Curated v1.5.6

Curated v1.5.6 adds optional comic and photo libraries, lets Agent work with those libraries when they are enabled, and sorts the movie wall by real ingestion time.

## Highlights

- Enable comic and photo libraries independently in Settings → Experimental. Add library roots, scan ZIP/CBZ archives, browse walls, open details, read comics, and view photo books without mixing those titles into the movie catalog.
- Add media from one dialog: movies stay always available, and comic or photo tabs appear only when that library Beta is on. Photo archives can be imported into the configured photo root.
- Browse books with search, tag, and comic favorite/read-status filters, numbered page-preview batches, and a shared reader HUD for mode, fit, and reading direction.
- Keep personal notes, a local 0–5 rating, and an editable display title on comic and photo details. Photo details can also persist tags. Photo page thumbnails are bounded JPEGs instead of full originals.
- When a book library is enabled, Agent can search, present, polish notes, and translate display titles for that library. Movie answers still require request-scoped references before publication.
- Turn PIN App Lock off from Settings → Security when Curated is not serving a non-loopback LAN address. Non-loopback listeners still require PIN.
- Sort the movie library by actual ingestion time. Same-day titles no longer fall back to catalog-code order. Existing date-only added dates are promoted from the original index timestamp on upgrade.

## GitHub Release Body

Curated v1.5.6 adds optional comic and photo libraries, connects Agent to those libraries when they are enabled, and sorts movies by real ingestion time.

### What's Changed

**Comic and photo libraries**

- Turn comic or photo libraries on independently in Settings → Experimental. Disabled libraries hide their navigation and stop watching folders; existing indexes and archives are kept.
- Scan ZIP/CBZ books from configured roots, browse virtualized walls, open details, read comics, and view photo books. These catalogs stay separate from movies.
- Add media from one dialog. The movie tab is always present; comic and photo tabs appear only when that Beta is enabled. Photo ZIP/CBZ files import into the configured photo root without overwriting existing archives.
- Filter comic and photo walls with search and exact tags; comics also support favorite and read-status chips. Page previews use numbered batches and natural image proportions.
- Overlay a compact reader HUD for back, title, progress, and reading settings. Comic and photo details support personal notes, a local half-star rating, and an editable display title. Photo details can persist tags. Photo thumbnails are bounded JPEGs.

**Agent and security**

- When a book library is enabled, Agent can search it, show book cards, polish notes, and translate display titles. Insights, Saved Views, ratings, source-page tools, and movie-only write tools stay movie-only.
- Movie chat answers still require request-scoped references before publication; unsupported catalog claims are rejected after one correction.
- Disable PIN App Lock from Settings → Security when Curated is not listening on a non-loopback address. LAN listeners still require PIN.

**Movie library**

- Sort by added time using the actual ingestion timestamp. Titles added on the same calendar day no longer reorder by catalog code. Existing libraries pick up the original index time automatically on this upgrade.

### Getting Started

- This release supports Windows x64. Use the installer for normal installation, or the portable ZIP for manual deployment.
- Comic and photo libraries default off. Enable each one in Settings → Experimental, add an absolute library path, then scan ZIP/CBZ archives from that path’s more-actions menu.
- AI remains opt-in and defaults to disabled. Enable it in Settings → AI and configure your own OpenAI-compatible provider. Book tools appear only after the matching library Beta is on.
- Curated packages are unsigned; verify the published SHA-256 values when distributing or mirroring artifacts. The Windows packages include FFmpeg.
