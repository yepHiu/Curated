# Curated 20261008

## GitHub Release Body

Updates Server and Desktop with frame image loading fixes, native playback improvements, and library management fixes.

### Module updates

| Module | Status | Before | After |
| --- | --- | --- | --- |
| Server | Updated | 1.7.10 | 1.7.11 |
| Desktop | Updated | 0.2.5 | 0.2.6 |

### What's Changed

- **Frame library:** resolves captured frame images against the same API base as other requests, including local development and custom Server addresses.
- **Server AI:** allows deleting inactive tag organization history while preserving applied tags; improves prompt cache reuse and records cache usage.
- **Server metadata:** retries interrupted FC2 metadata connections.
- **Server library:** shows complete movie filenames in the part selector and aligns photo/comic storage path actions with the movie library.
- **Server backups:** keeps long-running backup requests alive.
- **Notifications:** automatically closes completed progress and route failure notifications; simplifies the tag organization dialog.
- **Windows Desktop:** captures native playback frames without pausing the video and enlarges the default native playback window.

### Upgrade Notes

- Install only the components with updates. Existing library data and Desktop connections are retained.
- Old all-in-one installations require the [Full 1.7.3 migration](https://github.com/yepHiu/Curated/releases/tag/full-v1.7.3) first.
