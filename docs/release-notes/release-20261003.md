# Curated 20261003

## GitHub Release Body

This Server update improves AI tag organization for large libraries and adds wishlist membership lookup for the browser plugin. Desktop remains at 0.2.3.

### Module updates

| Module | Status | Before | After |
| --- | --- | --- | --- |
| Server | Updated | 1.7.7 | 1.7.8 |
| Desktop | Unchanged | 0.2.3 | 0.2.3 |

### What's Changed

- Organize AI tags for one movie, a selected group of up to 600 movies, or the entire library.
- Follow organization progress in the sidebar and review a more compact task history.
- Reuse existing user labels before creating new ones, without a cumulative topic limit. Original NFO tags are preserved.
- Improve large-library organization with faster task creation, resumable work, fault handling and paged topic vocabularies.
- Fix AI prompt loading across Windows line endings.
- Add wishlist membership lookup so compatible browser plugins can show whether a title is already saved.

### Upgrade Notes

- Install only the components with updates. Existing library data and Desktop connections are retained.
- Desktop 0.2.3 remains compatible and does not need to be reinstalled. The updated business interface is served by Server 1.7.8.
- Old all-in-one installations require the [Full 1.7.3 migration](https://github.com/yepHiu/Curated/releases/tag/full-v1.7.3) first.
