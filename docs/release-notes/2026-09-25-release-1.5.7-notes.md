# Curated v1.5.7

Curated v1.5.7 adds a wishlist with browser plugin integration, expands batch management for comic and photo libraries, and polishes movie playback, personal insights, and settings.

## Highlights

- Save code-only movie wishes, browse them as a poster wall, preserve source page links and images, and use the browser plugin connection to enrich entries. Movie details also show playback availability checks for Jable and MISSAV with links for manual follow-up when a site blocks automated checks.
- Batch favorite, tag, and delete comic and photo library entries. The two libraries now share the same toolbar behavior.
- Translate movie titles and summaries in place with the configured AI provider. Player screenshot and video-to-GIF controls sit beside a truncated title; capture feedback and progress labels are clearer.
- Personal Insights uses a more compact layout without card or ranking borders. Movie, comic, and photo cards use hover borders to indicate pointer position.
- Settings has reorganized navigation, local multilingual fonts, and an About section listing key third-party licenses. Agent context capacity can be configured and conversation checkpoints preserve continuity.
- Portable backups include wishlist images. LAN access settings can be configured independently of the local PIN lock, with restart guidance for live changes.

## GitHub Release Body

Curated v1.5.7 adds a wishlist with browser plugin integration, expands batch management for comic and photo libraries, and polishes movie playback, personal insights, and settings.

### What's Changed

**Wishlist and browser plugin**

- Save movie wishes by code, browse their poster wall, keep source page links and images, and enrich them through the optional browser plugin connection.
- Check playback availability on Jable and MISSAV from movie details. When a site blocks the check, Curated explains the result and offers a manual link.
- Portable backups now include wishlist images.

**Libraries and playback**

- Batch favorite, tag, or delete comic and photo library entries.
- Movie, comic, and photo cards show a border on hover. Personal Insights summary cards and rankings use a cleaner borderless layout.
- Translate movie titles and summaries in place using the configured AI provider.
- Player screenshot and GIF tools align with the title, which truncates when needed. Progress labels and capture feedback have been refined.

**Settings and Agent**

- Reorganized settings navigation, added local multilingual fonts, and listed key third-party licenses in About.
- Configure Agent context capacity and preserve conversation continuity with checkpoints.
- Configure LAN access independently of the local PIN lock; settings explain when a restart is needed.

### Getting Started

- This release supports Windows x64. Use the installer for normal installation, or the portable ZIP for manual deployment.
- Comic and photo libraries remain optional. Enable them in Settings → Experimental.
- AI and the browser plugin remain opt-in. Configure the services you want from Settings.
- Curated packages are unsigned. Verify the SHA-256 values below when distributing or mirroring them. Windows packages include FFmpeg.
