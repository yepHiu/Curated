# Curated v1.5.5

Curated v1.5.5 adds an opt-in library Agent, AI settings and usage records, and substantial reliability improvements for playback, frame capture, and short clips.

## Highlights

- Work with the library through a docked Agent panel with resizable width, page context, mentions, persistent conversations, and earlier-message pagination.
- Review tool evidence and ambiguous movie or actor matches before acting. Preview supported edits before confirming them; stale previews are rejected, and durable receipts prevent identical confirmation retries from applying an edit twice.
- Translate and polish supported text in place, with cancellation and explicit review before applying changes.
- Configure an OpenAI-compatible provider in Settings → AI. Provider and policy fields save automatically; connection tests remain explicit. Read-only mode, tool and confirmation limits, retention controls, and paginated request/audit records are available.
- Improve HLS startup, seeking, recovery, and concurrent playback isolation. Frame stepping follows the source media cadence, and update installers keep running independently of their initiating HTTP request.
- Queue frame captures with preview receipts, retry/download/compress/undo actions, bounded 4K encoding, source-frame extraction, and original-pixel inspection.
- Browse large frame collections with cursor pagination and offscreen row unloading; review visually similar frames without automatic deletion. Generate bounded GIF, MP4, or WebM clips using actual media timing.
- Check duplicate movie codes before import, improve narrow-pane toolbar wrapping, and load optional English/Japanese dictionaries as JSON assets.
- Update PostCSS and nanoid to patched versions and refresh regression tests for virtualized frames and responsive controls.

## GitHub Release Body

Curated v1.5.5 brings an opt-in library Agent, dedicated AI settings, and smoother playback and frame capture.

### What's Changed

**Agent and AI**

- Open the Agent beside your library in a resizable panel, with page context, mentions, saved conversations, and access to earlier messages.
- See tool evidence and choose between ambiguous matches. Supported library edits require a preview and confirmation; changed data invalidates stale previews, and retrying an identical completed confirmation does not repeat the edit.
- Translate and polish supported text in place, with cancellation and review before applying it.
- Manage the provider and AI policy in Settings → AI with automatic saving, explicit connection tests, read-only mode, usage limits, and request/tool audit history. Token totals use provider-reported counts; missing usage remains unknown.
- Recover partial replies and preserve completed tool evidence when a response is interrupted.

**Playback and library**

- Improve HLS startup, seeking, error recovery, and isolation between concurrent playback sessions.
- Step through video using the source frame cadence.
- Check duplicate movie codes before import and keep library toolbar actions usable in narrower content panes.
- Keep a launched update installer alive after the initiating request ends.

**Frames and clips**

- Queue screenshots with thumbnail receipts and retry, original download, optional JPEG compression, and undo controls.
- Extract frames from the source video and inspect original pixels in the image viewer.
- Handle 4K encoding with bounded background work and browse large frame collections with less offscreen image retention.
- Review visually similar frames without automatic deletion.
- Generate short GIF, MP4, and WebM clips with bounded jobs and timing based on actual media playback.

**Maintenance**

- Update PostCSS and nanoid to patched versions.
- Load optional English/Japanese dictionaries as JSON assets and refresh regression coverage.

### Getting Started

- This release supports Windows x64. Use the installer for normal installation, or the portable ZIP for manual deployment.
- AI is opt-in and defaults to disabled, including when upgrading from the older browser-only experimental switch. Enable it in Settings → AI and configure your own OpenAI-compatible provider.
- AI requests use your configured provider. Persistent chats and confirmed library edits use the local Go backend included in the desktop package. Library edits still require explicit preview confirmation.
- Source-frame extraction and clip generation require readable source media; the Windows packages include FFmpeg.
