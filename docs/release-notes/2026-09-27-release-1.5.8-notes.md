# Curated v1.5.8

Curated v1.5.8 adds saved Desktop server connections, restricts server administration to local clients, and unifies empty library pages.

## Release metadata

- Package version: `1.5.8`; Server: `1.5.8`; Desktop: `0.1.0`.
- Platform: Windows x64, existing all-in-one installer and portable distribution.
- Source: the immutable commit selected by tag `v1.5.8`; the packaged manifest records `sourceCommit` and the build timestamp.
- Build: GitHub Actions **CD - Windows release**, with `VITE_USE_WEB_API=true` and CI checks against the tagged commit.
- Artifacts: `Curated-Setup-1.5.8.exe`, `Curated-1.5.8-windows-x64.zip`, `release.json`, `SHA256SUMS.txt`.
- Checksums are generated from the actual packages during CD and verified against GitHub after upload.

## GitHub Release Body

Curated v1.5.8 makes it easier to switch between servers, clarifies which settings belong to your device, and gives empty libraries a consistent, friendly appearance.

### What's Changed

**Desktop server connections**

- Save named servers, add a server from Settings, and switch or reconnect through the server manager. The last successful connection is restored on startup.
- See the current server address, connection status, and saved servers in Network & devices.
- Keep each server's session separate. A failed remote connection keeps the current page available instead of starting an unrelated local server.

**Settings and updates**

- Server-wide settings, library directory changes, security administration, AI configuration, and maintenance actions now require access from the server's own computer. Remote clients retain device preferences, library browsing, uploads, and normal session lock/unlock.
- Remote settings responses omit AI and proxy credentials. Unavailable administration sections and controls are hidden.
- Remote Desktop connections no longer expose Server installer actions. About shows the Server and Desktop versions separately, with build timestamps and a shared update-check action.
- Settings use clearer ownership labels and contextual hints.

**Libraries and presentation**

- Movie, actor, comic, photo, wishlist, history, and other media pages share a consistent empty state. Search and filter results use a separate message and relevant recovery actions.
- Library paths you deliberately remove now stay removed after a restart, including an intentionally empty path list.
- Refined sidebar spacing, app icons, locally bundled brand typography, and About controls.

### Upgrade Notes

- This release remains a Windows x64 all-in-one package. It includes Server 1.5.8 and the initial Desktop 0.1.0 component identity; independent Desktop, Server, and Full installers are not included.
- Server sessions are now isolated by address and port. You may need to unlock a saved server again after upgrading.
- If an older version already restored a deleted library path, remove that path once more after this upgrade; existing paths are not deleted automatically.
- Configure server-wide settings directly on the server computer. Remote users can continue using their libraries and uploading to configured destinations.
- Windows packages remain unsigned and include FFmpeg. Verify downloads using the attached `SHA256SUMS.txt`.
