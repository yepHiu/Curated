# Curated v1.4.10

Curated v1.4.10 improves browsing flow in large actor and Curated Frames libraries by replacing manual "load more" pagination with automatic near-viewport loading. It also expands the public API reference and records the Android app foundation plan for future client work.

Build stamp: `20260619.053836`

## Highlights

- Added automatic incremental loading to the actor library. More actor cards now load as the user approaches the end of the scroll area, while preserving search and actor-tag filters.
- Added automatic incremental loading to Curated Frames timeline, actor, and movie views. Frame rows now continue loading near the bottom of the scroll container without requiring a manual load-more button.
- Kept guarded fallback behavior for loading states and scroll events so large lists can continue paging even when the browser does not support `IntersectionObserver`.
- Expanded `API.md` with the current backend API surface.
- Added `docs/plan/2026-06-07-curated-android-app-foundation.md` to document the Android client foundation direction.
