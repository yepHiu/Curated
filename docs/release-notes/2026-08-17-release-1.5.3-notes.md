# Curated v1.5.3

Curated v1.5.3 is a playback-performance and player-navigation release. It starts mid-stream HLS from nearby keyframes instead of always transcoding, shortens time to first frame, and marks curated frames on the player progress bar.

## Highlights

- Resume and out-of-window seeks now prefer stream-copy remux from the last video keyframe in a 30-second window, with a precise transcode fallback only when no keyframe is found.
- HLS FFmpeg sessions pace input at 2.5x realtime, probe available hardware/software encoders before startup, and reuse persisted media-probe results across restarts.
- Direct `/stream` responses now carry a strong size+mtime ETag, and playback planning can narrow mp4-family direct play using the browser's reported video codecs.
- Player startup fetches a single movie detail and prefetches the playback descriptor instead of loading the full library first; locked startup stays free of protected playback prefetch.
- The player progress bar shows clustered curated-frame ticks, a below-track count for dense groups, paired hover triangles, and a hidden slider thumb so the media timeline stays readable.

## GitHub Release Body

Curated v1.5.3 makes playback start faster and easier to navigate: mid-stream HLS remuxes from nearby keyframes, first-frame work is shorter, and curated frames appear on the progress bar.

### What's Changed

- Resume and seeks outside the current HLS window start from the last nearby video keyframe with stream-copy remux, and only fall back to precise transcode when no keyframe is found.
- Pace FFmpeg session input at 2.5x realtime, probe encoder support before startup, and reuse media-probe results across restarts.
- Add a strong size+mtime ETag to direct movie streams, and let the browser report playable codecs so HEVC/AV1 titles go to HLS when the current tab cannot decode them.
- Load one movie detail and prefetch the playback descriptor before the first frame, without touching protected playback endpoints on the lock screen.
- Mark curated frames on the player progress bar, cluster nearby ticks, show dense counts below the track, and keep the timeline readable on hover.
