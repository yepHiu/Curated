# 设置页分类治理建议（2026-09-25）

> 状态：已按本方案实施设置页导航与内容归位。漫画/写真使用独立 `comics` / `photos` 深链；`experimental` 旧链接定向漫画库。窄屏使用原生分组选单。

## 现状与问题

当前设置页在侧栏平铺 12 个同级入口：概览、通用、安全、影片存储、元数据刮削、网络、萃取帧、播放设置、维护、实验性功能、AI、关于。窄屏则把同一组入口放在横向滚动的标签栏。

实际内容已有几处跨类：

- 「概览」混合资料库数字、观看时间和已连接客户端；客户端更接近访问与连接管理。
- 「通用」同时包含语言与外观、自动下载更新、开机启动、前后端日志；日志属于诊断，更新开关宜与「关于」里的检查更新放在一起。
- 「网络」含局域网访问、代理及浏览器插件联动。浏览器插件联动现在由 `SettingsWishlistSection` 呈现，名称容易让人误以为属于心愿单设置。
- 「实验性功能」目前承载漫画库和写真库的完整设置，包括路径、自动监听、阅读/查看与缓存。它们首先是内容库，其次才是 Beta。
- 「维护」含资料库健康、备份和全量扫描；「关于」又含应用更新、开发工具和诊断入口。

## 推荐的信息架构

「概览」固定在导航顶部，作为状态首页；下面用四个可见分组标题组织设置入口。分组标题不作为可点击页面，桌面侧栏保留短标签，窄屏可用分组菜单或可折叠列表，避免 13 个标签连续横向滚动。

| 分组 | 入口 | 放置的内容 |
| --- | --- | --- |
| 使用与功能 | 通用 | 语言、地区、外观、开机启动。 |
| 使用与功能 | 播放 | 播放方式、转码、硬件编解码、原生播放器、快进快退。 |
| 使用与功能 | 萃取帧 | 保存方式、格式、导出目录、快捷键、反馈音。 |
| 使用与功能 | AI 助手 | 启用与权限策略、模型和服务商、用量、审计与清理。 |
| 资料库 | 影片库 | 影片目录、默认导入目录、扫描和整理规则。沿用现有 `library` 深链。 |
| 资料库 | 元数据 | 刮削源、策略、自动化和手动触发。沿用现有 `metadata` 深链。 |
| 资料库 | 漫画库 · Beta | 启用、路径、自动监听、阅读器和缓存。 |
| 资料库 | 写真库 · Beta | 启用、路径、自动监听、查看器和缓存。 |
| 访问与连接 | 网络与设备 | 局域网访问、代理、浏览器插件联动、已连接客户端。 |
| 访问与连接 | 安全 | PIN、自动锁定、受信任设备与会话。 |
| 系统 | 维护与备份 | 资料库健康、备份、全量扫描、前后端日志；开发诊断可置于此页的高级区。 |
| 系统 | 关于与更新 | 版本、检查/下载更新、自动下载更新、许可和仓库链接。 |

概览保留资料库数字和观看时间。已连接客户端的完整列表移到「网络与设备」；概览如需保留状态感，只显示客户端数量并链接到详情。漫画、写真是否为 Beta 只影响徽标和提示，不决定它们的导航位置。「实验性功能」在当前内容移走后撤除；日后出现跨领域实验开关，再评估是否恢复一个集中入口。

## 为什么这样分

1. **按用户要完成的事找入口**：调整播放找「播放」，管理漫画找「漫画库」，排查设备访问找「网络与设备」。不要求用户先判断实现状态或技术模块。
2. **同一件事放在一起**：自动下载更新与手动检查更新共处一页；日志与诊断共处维护；连接设备列表与局域网访问共处网络。
3. **控制导航层级**：只增加视觉分组和两个实际内容库入口，不再以「实验性」承载大块业务设置。先用页面内卡片分区，不增加第三层导航。
4. **保留已有定位方式**：`?section=library` 等已有 slug 不变；漫画/写真使用独立 slug，旧 `?section=experimental` 固定定向漫画库，两个 Beta 入口始终可见，方便重新启用。

## 建议的实施顺序

1. **先改导航与命名**：添加分组标题、调整顺序、明确「影片库」「AI 助手」等标签；保持内容组件和保存逻辑不动。
2. **移动少量跨类卡片**：已连接客户端移到网络；更新开关移到关于与更新；日志和开发诊断移到维护。迁移时保持原保存状态和错误提示。
3. **拆出 Beta 内容库入口**：漫画与写真分别独立成页，保留 Beta 徽标与关闭时的数据保留说明；处理旧深链。
4. **核对导航体验**：检查桌面侧栏、窄屏入口、键盘/读屏分组语义、三语文案、刷新后的当前页和从其他页面跳转到设置的深链。可用少量典型任务检验：找代理、改漫画目录、查看已连接设备、检查更新、导出备份。

本建议只涉及信息架构与页面组织；不要求修改后端配置字段或设置的持久化方式。实现阶段仍需逐项检查 `SettingsPage.vue` 中以 section slug 触发的数据加载和按需渲染，避免移动卡片后产生额外请求或保存时状态丢失。


## 2026-09-27 远程设置审查与屏蔽（已实施）

远程端定位为资料库使用端；服务器全局配置先统一保留给 Server 所在电脑的直接 loopback 连接。本轮不新增角色、配置字段或数据库迁移。

| 分类 | 设置与操作 | 处理 |
| --- | --- | --- |
| 必须屏蔽：主机与访问安全 | 开机启动、局域网开放、代理与认证、浏览器插件启用、PIN 设置/变更/关闭、全局会话期限/重启锁定、受信任设备撤销 | 隐藏管理控件，后端拒绝远程操作；当前会话解锁/锁定保留 |
| 必须屏蔽：主机文件与维护 | 路径增删改/默认目标（已有）、备份创建/验证/恢复预检、资料库健康扫描/修复/清理、服务端日志、安装更新（已有） | 目录状态只读；维护导航隐藏；Debug 中服务端日志也隐藏 |
| 必须屏蔽：执行与凭据 | FFmpeg/硬件转码、服务端原生播放器配置、AI 服务商/密钥/权限与治理 | 后端限制全局配置写入；远程设置响应去掉 AI 密钥及 Base URL、代理地址及认证；禁缓存 |
| 建议屏蔽：影响所有客户端 | 整理、监听、自动刮削、刮削源与策略、漫画/写真启用及缓存、全局阅读/播放默认值、萃取帧导出格式/水印默认值、自动下载更新 | 本轮一并屏蔽，避免把全局选项误当当前设备偏好 |
| 建议屏蔽：管理信息与诊断 | 已连接客户端、AI 用量/审计/清理、代理/刮削源/AI 连通性测试 | 远程隐藏管理页面并限制对应接口 |
| 保留 | 语言/主题、概览、当前会话锁屏、当前设备截图保存方式/目录/快捷键/提示音、当前设备播放器协议模板、Desktop 服务器切换和 Desktop 更新、版本信息 | 继续使用；只读目录保留；播放、阅读器单本偏好、上传、收藏评分、AI 聊天等业务接口沿用现有权限 |

实现复用 `useServerLocalAccess` 与 `isDirectLocalRequest`。未知、旧服务端、LAN 地址、转发请求均不显示本机管理控件；本机探测尚未完成时保留深链意图，确认远程后将不可用的 `metadata` / `maintenance` / `ai` 页面回到概览。远程浏览器隐藏无可用内容的网络导航，Desktop 保留本机连接管理。

`PATCH /api/settings` 统一为本机操作，含默认目录字段也返回 `403 SERVER_SETTINGS_READ_ONLY`；三库路径 CRUD 继续返回 `LIBRARY_PATHS_READ_ONLY`。25 个管理路由共用同一服务端拦截，避免仅靠前端隐藏。远程模拟只改变 UI，不改变后端权限。代理必须保留来源证据，不能剥离全部 Host/Origin/转发信息后期望后端识别远程。

验证包含设置导航和深链、探测前后切换、真实远程/未知/模拟状态、混合卡片、播放模板仅本地存储、管理路由 403、密钥响应脱敏、本机管理、远程锁屏/解锁与上传回归。多端布局仍使用原有导航与卡片约束；本轮未执行跨浏览器显示缩放套件。若未来要允许远程管理，应先引入明确的管理身份和能力契约；若希望远程修改播放/阅读默认值，应先将这些偏好迁移到设备或用户作用域。
