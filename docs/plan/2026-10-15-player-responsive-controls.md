# 播放器控制栏统一与宽度适配

日期：2026-10-15。状态：已实现、本地验证，未发布。

## 目标与实现

Web 与正式 Desktop 原生共用 PlayerTransportControls 的单行控制栏与容器断点。Web 截图和片段操作移至底部，逐帧、源帧、片段格式保留在捕获菜单。补齐底栏连续播放和播放信息入口，原生上一部/下一部移入共享播放组插槽。保持各引擎能力差异，不调整播放引擎或 API。

| 控制栏可用宽度 | 收缩行为 |
| --- | --- |
| ≤960px | 隐藏捕获高级菜单、画中画 |
| ≤760px | 音量区域只保留静音按钮 |
| ≤640px | 隐藏连续播放、引擎切换、Info |
| ≤480px | 隐藏未录制的捕获按钮、上一部和下一部 |
| ≤360px | 隐藏快退和快进 |

播放、静音、设置、全屏始终保留；录制中的停止按钮不隐藏。隐藏属于界面收缩，不清除功能状态。断点按容器宽度判断，适用于侧栏及不同窗口宽度。

## 验证

- pnpm typecheck：通过。
- 三个变更 Vue 文件的 ESLint、git diff --check：通过。
- 播放器与原生捕获/音量的 8 个测试文件、50 项测试：通过。首次默认并发出现 5 秒超时，限制为 2 workers、15 秒超时后全部通过。
- 使用 Chromium 挂载真实共享控制组件，填入两端动作数量的按钮，检查 1200、961、960、800、761、760、641、640、481、480、361、360、288、240px 共 14 个容器宽度：无按钮越界；288px 下录制停止按钮可见。
- 本轮未进行真实原生视频层合成或生产安装包验证。
