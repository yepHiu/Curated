# 漫画与写真库界面及预览优化

状态：verified

## 范围与决策

对齐影片库现有视觉：排序收进圆角工具栏菜单，保留各库领域与已有能力；统一计数、搜索状态、加载骨架与空态。详情强化封面、标题、页数、继续阅读、源文件信息和返回路径。写真没有实现的管理动作不再呈现为可点击的空操作。

固定前 12 页改成容器宽度决定每批数量（4–20 张）的分页预览，卡片按图片实际比例自适应宽度并换行，上一批/下一批与数字批次分页可访问全部页；切换只保留一批 DOM，图片接近视口才设置源地址，失败可重试，点击直接从对应页阅读。保留全书页元数据接口，避免为本次 UI 改动引入新分页后端契约。

写真缩略图接口生成最长边 420px 的真实缩略图，以有界内存 LRU 缓存及串行生成限制资源使用，源归档变化使缓存失效；浏览原图接口保持原分辨率。漫画继续使用现有缩略图缓存。AI 范围保持影片。

## 验证

测试预览批次边界、容器适配、数字分页与省略号、请求延迟、图片错误重试、来源切换重置；回归两库页面/详情/卡片。验证缩略图大小、缓存命中/失效和资源限额。执行类型检查、Lint、生产构建、相关 Go/Vitest，以及隔离数据的浏览器桌面与窄屏检查。按功能提交，文档单独提交，不 push。

## 实现与验收结果

- 媒体信息收纳：漫画/写真主区不再显示源文件和存储位置，仅保留页数、添加时间。两库右上角采用影片同款 36px 三点按钮，通过“媒体信息”打开共用 `BookMediaInfoDialog.vue`，以只读字段展示源文件名、完整路径、文件格式、页数、添加/更新时间；长文本换行，缺失值用占位符，切换书籍自动关闭。漫画原有管理菜单保留，写真仅新增已实现的信息入口。中英日文案齐全；24 项组件/详情测试、类型检查和 ESLint 通过；实际两库菜单与弹窗内容核对通过，写真长路径无横向溢出、关闭按钮正常。

- 预览卡片比例统一：漫画/写真移除固定 2:3 框，图片加载后使用自然宽高比决定卡片宽度，沿用影片的 160/176/192px 目标高度、16px 圆角、12px 间距及自动换行。卡片宽度受容器限制，缩窄时高度同步按比例缩小；保留原始比例，不再以固定框居中留白。每批容量仍为 4–20 张，实际行数随图片比例变化。桌面实测横图 420×315 对应 256×192 卡片，竖图 252×420 对应约 115.2×192 卡片；15 项相关测试、类型检查与 ESLint 通过。本次浏览器视口覆盖未作用于检查页，未将窄屏浏览器检查计入验收。

- 影片详情内边距修正：`DetailPanel` 的 Card 设置 `py-0`，去掉默认 `py-6` 与内容层 padding 的叠加；保留内容层 `p-5 sm:p-6`，使桌面封面/标题顶部与封面左侧净留白均为 24px（此前顶部 48px）。真实影片详情实测一致，9 项详情测试和文件级 ESLint 通过。

- 添加媒体目标目录统一：影片、漫画、写真均复用 `ImportTargetPath.vue`，沿用影片的横向标签/路径布局、圆角、边框、背景与内边距，标签统一为“目标目录”；长路径省略并通过 title 提供完整内容，各库缺省路径提示保留。真实三个 Tab 实测目录区域宽高、padding 与边框一致；26 项导入相关测试、类型检查及 ESLint 通过。

- 添加标签直接复用影片组件：将影片原有内联控件提取为 `DetailTagAddControl.vue`，影片、漫画、写真详情均引用同一组件；统一 29px 添加按钮、36px 输入条与图标取消按钮。支持 Enter 添加、Esc/点击外部收起、中文输入法保护、64 标签/64 Unicode 字符校验；成功清空草稿并保留输入条，漫画/写真异步保存失败保留草稿并允许重试，保存期间防止重复提交。影片联想与各库数据保存边界保持独立。29 项相关测试、类型检查及 ESLint 通过；真实漫画与写真页面均实测按钮 29px、输入条 36px，展开自动聚焦，未写入真实标签数据。

- 写真标签补齐：详情标签区支持添加、Enter 保存、Esc 取消、重复去重、失败保留草稿；`PATCH /api/library/photos/books/{id}/tags` 以事务替换独立写真标签，返回更新详情。最多 64 标签、每项 64 Unicode 字符；缺失/null/非法字段返回 400，未知册返回 404，关闭 Beta 拒绝写入。Web 更新共享写真缓存，Mock 使用独立 localStorage。组件、服务与 HTTP/SQLite 回归覆盖保存、校验、失败重试和 Beta 限制。

- 库页：菜单式排序、册数、搜索清除、骨架/空结果/错误重试；保留漫画批量操作。卡片标题单行显示，超出省略、键盘焦点可见、图片异步解码，未开始的册不再显示误导性进度条。
- 详情：保留壳层返回入口；封面可从第一页打开，标题附近放主操作，主区保留页数/添加日期，源文件与路径移至“更多 → 媒体信息”弹窗；写真未接通的管理动作不显示。路由切换时忽略旧请求，避免晚到响应覆盖当前册。
- 详情间距统一：页面外边距由 AppShell 提供，两库详情移除重复 padding，采用影片详情相同的 `overflow-y-auto pr-2` 滚动容器。封面列使用有上限的 `fit-content` 跟随实际图片宽度，避免固定列宽留下空白；卡片内 padding 与列间 gap 在桌面均为 24px。实测漫画和写真标题/预览卡片左右边缘重合，较窄漫画封面的两侧间隔均为 24px；375px 漫画页面正常堆叠且无横向溢出。相关 22 项测试与 ESLint 通过。
- 预览：按图片实际比例自适应卡片宽度并换行，每批 4–20 张，上一批/下一批替换 DOM；数字批次分页、当前批次高亮、首末批直达、省略号；移除页码输入/定位/打开此页按钮，点击缩略图进入对应页。使用 IntersectionObserver 延迟 src，原比例完整预览、低优先级异步解码、失败重试。
- 写真 `/thumbnail`：最长边 420px JPEG，32 MiB 内存 LRU；串行生成，32 MiB 源字节 / 24M 源像素上限；档案 size/mtime 变化失效；私有 ETag/304。生成失败不退回大原图，原 `/image` 保持原始字节。后端提交 `6dead3c0`。
- 20 个相关 Vitest 文件累计 69 项通过，含旧两库卡片/详情/阅读器、路由与新预览行为；`pnpm build`（typecheck + 原 bundle 预算）与 `pnpm lint` 通过。`go test ./internal/photothumb/ ./internal/server/`、对应 `go vet` 通过，验证尺寸、缓存/源变更、304、禁用门禁、原图不变。
- 初版预览验收（当时含页码定位；现已改为数字批次分页）：独立 8186 后端、测试数据库与 80 页合成图集验收：两库排序/详情，1280 桌面与 375px 预览；手机仅 4 个节点，定位 80 后显示 77–80，打开路由为 `/view/79`（界面第80页）。缩略图请求约 7–8 KiB/张（仅此合成样本）；进入阅读器前不请求页原图。无横向溢出。
