# 漫画详情操作收纳与封面尺寸调整方案

## 背景

漫画详情页第一版已经对齐影片详情页的左封面、右信息结构，但当前实现把标题、标签、评分、收藏编辑控件直接铺在详情页上。用户确认希望详情页默认保持浏览态，编辑与管理操作通过类似影片详情页右上角三点菜单进入。

同时，当前影片详情页左侧封面媒体列在宽屏下占位偏大。漫画竖版封面若复用同样尺寸，会进一步放大这个问题。因此本次调整同时收窄影片与漫画详情页的左侧媒体列。

## 确认设计

1. 漫画详情页默认展示信息，不直接展示标题、标签、评分、收藏编辑表单。
2. 漫画详情页右上角提供三点更多菜单，菜单项包括：
   - 编辑漫画信息
   - 在文件管理器中显示
   - 删除漫画
3. 编辑漫画信息通过独立弹窗完成，字段限于 MVP 已确认的标题、标签、评分、收藏。
4. 删除漫画通过确认弹窗完成，调用现有漫画服务边界 `deleteComic`，删除成功后返回漫画库列表。
5. 在文件管理器中显示调用现有漫画服务边界 `revealComicSource`；Mock 模式失败时只显示错误，不引入影片服务。
6. 影片与漫画详情页左侧媒体列统一从 `lg:30rem / xl:34rem` 收窄到 `lg:24rem / xl:28rem`，保留左封面、右信息的详情页结构。

## 实施范围

- 修改漫画详情展示组件，加入三点菜单，移除内联编辑表单。
- 新增漫画编辑弹窗组件。
- 新增漫画删除确认弹窗组件。
- 修改漫画详情路由页，接入删除与显示源文件动作。
- 调整影片详情页和漫画详情页媒体列尺寸。
- 更新相关单元测试，按 TDD 验证行为。

## 非目标

- 不新增漫画作者、系列等独立字段；作者仍可用标签表达。
- 不把漫画数据并入影片模型或影片服务。
- 不改变后端接口契约。
- 不运行显示缩放冒烟测试，除非用户另行明确要求。
