# Agent 图标建议

日期：2026-09-06
状态：候选建议，尚未选择或实施。

## 当前依据

- Agent 入口位于 `src/layouts/AppShell.vue`，使用 `lucide-vue-next` 的 `Bot`，图形为 `size-5`（20px）。
- 入口使用中性色，窗口打开时已有 `text-primary` 状态。
- 项目多处使用 `Sparkles`，包括品牌展示、AI 润色以及其他业务操作，作为 Agent 专属身份的区分度有限。
- 遵循现有线性图标风格、主题令牌及小尺寸可辨识要求。

## 候选方向

| 候选 | 视觉与含义 | 取舍 |
| --- | --- | --- |
| Lucide `Orbit`（现成图标首选） | 中心与轨道，抽象表达围绕资料库工作的助手；轮廓较有辨识度 | AI 含义需要通过现有 Agent 提示文案建立 |
| 定制「C + 星点」（品牌方向首选） | 开口 C 轮廓与一个简洁星点，关联 Curated 与智能助手 | 需绘制 SVG，并在 16/20/24px 下检查细节，避免缩小时星点与 C 粘连 |
| Lucide `MessageCircle` | 对话语义直接，外观轻巧 | 更像聊天或客服，与通知中心使用的 `MessageSquare` 同属气泡语义，区分度较弱 |

## 建议

希望低成本改善现有入口时优先试 `Orbit`；希望 Agent 成为可长期识别的产品角色时，优先设计「C + 星点」。保留单色线性表达，线宽与相邻 Lucide 图标一致，打开状态沿用主题主色。不要为常驻入口增加持续旋转、发光或呼吸动画。

选定后在真实顶栏中检查浅色、深色及 20px 显示效果，保留按钮现有可访问名称与交互区域。

## 第二轮候选

用户希望查看更多方向，以下为新增候选，不代表已选定。

| 候选 | 气质与适配理由 | 取舍 |
| --- | --- | --- |
| Lucide `Aperture`（光圈） | 规整、精致，与影像资料库主题契合，可表达聚焦和理解内容 | 更容易被理解为摄影或影像功能；需检查 20px 下内部线条密度 |
| Lucide `Waypoints`（连接节点） | 表达关联信息、协调多个步骤，贴合 Agent 的工具调用能力 | 偏技术感，可能联想到工作流或关系图 |
| Lucide `Origami`（折纸鸟） | 轻盈、有角色感，适合偏亲切的私人助手定位 | AI 语义较弱，需要通过长期一致使用建立认知 |
| Lucide `ScanEye`（扫描眼） | 表达查看、识别、理解，与资料检索有关 | 容易被误认作扫描或视觉识别入口 |
| Lucide `Asterisk`（星号） | 简单、紧凑，在小尺寸下容易保持清晰 | 语义抽象，可能像注释或必填标记；应避免刻意模仿现有 AI 品牌 |
| 定制「双眼」 | 两个短竖圆角笔画配极简外轮廓，有陪伴感且少于传统机器人细节 | 需要用外轮廓避免被看作暂停键，并检查与产品整体气质是否协调 |

第二轮优先考虑：希望贴合影像产品时试 `Aperture`；希望更有个性和亲切感时试 `Origami`；希望强调执行与工具协同时试 `Waypoints`。所有候选仍需结合真实顶栏评估，当前没有进行图标替换或视觉验收。
