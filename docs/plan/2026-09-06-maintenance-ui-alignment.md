# 设置维护页 UI 一致性修正

## 范围与依据

维护页用于资料库诊断、备份校验和手动扫描。沿用 `SettingsMetadataSection` 的单张设置卡片、短标题和 `p-4` 内嵌区块，遵守前端 UI 规范 §4.1；复用现有 shadcn-vue 控件，不修改服务合约或全局令牌。

## 本次修正

- 去掉健康扫描、手动扫描和备份表单中的重复边框与重复标题说明，保持区块标题左缘一致。
- 备份目录选择按钮紧邻输入框；创建、验证与预检操作靠右按内容收缩，取消半页宽按钮。桌面按钮恢复 32px 紧凑尺寸，手机操作保留 44px 高度并允许换行。
- 保留只读检查范围、远程路径含义、离线恢复边界和修复确认等有助于决定操作的说明；移除仅解释未来架构的“配置模型”占位区块。
- 健康报告、修复进度、错误和不支持状态继续使用现有语义状态色；长路径与操作组能在窄屏内收缩或换行。

## 验证

运行类型检查、相关 ESLint 与维护、健康、备份已有组件测试。浏览器核对桌面与 375px 窄屏，执行只读健康扫描查看报告；备份写入、修复和清理通过现有模拟测试验证。不运行完整显示缩放套件。

完成记录：类型检查与相关 ESLint 通过，3 个组件测试文件共 14 项通过。浏览器实测 1280px / 375px 的 document 宽度分别为 1280 / 375，无横向溢出；健康扫描、创建、验证、预检按钮桌面均为 32px 高，手机为 44px 高。核对深浅主题，实际只读扫描返回健康、0 项问题。未在真实资料库执行备份创建、修复或清理。
