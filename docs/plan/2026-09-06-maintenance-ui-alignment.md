# 设置维护页 UI 一致性修正

## 范围与依据

维护页用于资料库诊断、备份校验和手动扫描。沿用 `SettingsMetadataSection` 的单张设置卡片、短标题和 `p-4` 内嵌区块，遵守前端 UI 规范 §4.1；复用现有 shadcn-vue 控件，不修改服务合约或全局令牌。

## 本次修正

- 去掉健康扫描、手动扫描和备份表单中的重复边框与重复标题说明，保持区块标题左缘一致。
- 备份目录选择按钮紧邻输入框；创建、验证与预检操作靠右按内容收缩，取消半页宽按钮。桌面按钮恢复 32px 紧凑尺寸，手机操作保留 44px 高度并允许换行。
- 保留只读检查范围、远程路径含义、离线恢复边界和修复确认等有助于决定操作的说明；移除仅解释未来架构的“配置模型”占位区块。
- 健康报告、修复进度、错误和不支持状态继续使用现有语义状态色；长路径与操作组能在窄屏内收缩或换行。

## 验证

运行类型检查、相关 ESLint 与维护、健康、备份已有组件测试。浏览器核对桌面与 375px 窄屏，执行只读健康扫描查看报告；备份写入、修复和清理通过现有模拟测试验证。不运行完整显示缩放套件。

完成记录：类型检查与相关 ESLint 通过，3 个组件测试文件共 14 项通过。浏览器实测 1280px / 375px 的 document 宽度分别为 1280 / 375，无横向溢出；健康扫描、创建、验证、预检按钮桌面均为 32px 高，手机为 44px 高。核对深浅主题，实际只读扫描返回健康、0 项问题。未在真实资料库执行备份创建、修复或清理。


## 2026-09-29：胶囊按钮与任务流程打磨

### 问题

前一版主要调整密度和边框，仍使用 Button 的默认小圆角；创建、单独验证、恢复预检同时呈现，要求用户自己理解技术步骤。恢复条件检查与创建共用反馈，输入变更或请求失败可能留下旧的成功状态。浏览器目录选择器无法返回服务端所需的绝对路径，选择后还需手填。

### 已实施

- 页面按备份、健康检查、重新扫描排列。常规动作、健康修复/清理确认框、日志按钮统一 `rounded-full`；动作按内容收缩，桌面 32px、主要维护动作窄屏 44px。
- 备份只保留「保存到 → 立即备份 → 自动校验 → 文件路径回执」。成功创建后记住目录。覆盖范围就地说明，常规技术说明仍留在 SettingsHint。
- 「从已有备份恢复」按需展开，一个「检查备份并继续」完成包校验和恢复条件检查。可显式复用本次创建的备份，无需复制粘贴。没有新增在线恢复能力。
- 创建回执与恢复结果独立；更换路径或重试检查先清空旧结果；校验失败不报成功，保留已创建文件位置；忙碌期间防止重复提交。
- 浏览器直接粘贴 Server 本机绝对路径，只有存在桌面原生目录能力时显示文件夹选择按钮。
- 检查通过明确显示「尚未恢复」、目标数据库、退出 Server 的步骤与恢复指南；只关闭 Desktop 窗口不等于停服。
- 同步中文、英文、日文。没有修改 API、持久化字段或版本号。

### 能力边界

当前后端只支持离线恢复。完全图形化恢复需要后续实现 Server 的停服、离线替换、回滚与重启协作，不可把预检当成恢复完成。未增加服务器文件浏览器、备份历史列表或自动备份任务。

### 验证

- 4 个相关组件测试文件，23 项通过，覆盖目录记忆、创建后校验、校验失败、阻止恢复、重复提交、结果失效与复用新备份。
- 类型检查、改动文件 ESLint、生产构建通过；构建体积报告 0 项提醒/超限。
- Playwright 实际打开本地 Web API 页面，检查桌面 32px / 375px 窄屏 44px 胶囊按钮及恢复区展开；document 宽度与视口一致；英文浅色主题窄屏也无横向溢出。真实资料库未执行写入、清理或恢复。
