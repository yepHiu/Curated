# 添加媒体统一入口

状态：verified

日期：2026-09-11

## 范围

顶栏仅保留「添加媒体」，点击打开一个弹窗，内部用 Tab 选择「添加影片 / 添加漫画 / 添加写真」。影片始终显示；漫画与写真分别受对应 Beta 开关控制，默认不显示。关闭某一 Beta 时不保留可操作的隐藏类型。AI Agent 仍只处理影片。

## 实现

复用影片断点上传/番号检测、漫画 ZIP/CBZ 导入表单，支持嵌入共享弹窗，避免嵌套弹窗。切换 Tab 保留各自选择，上传中禁止切换和关闭。写真补齐独立 multipart 上传到默认写真路径与后续扫描，保留源文件、禁止覆盖重名目标，并将写入限制在配置的根目录内。前后端 Beta 门禁一致。

## 验收

覆盖四种 Beta 开关组合、统一入口、Tab 切换、上传中保护、影片既有导入回归、写真目标路径/格式/冲突/关闭门禁以及合成 CBZ 导入。检查三语言和窄屏弹窗。完成后补充结果，按功能及文档拆分提交，不 push。
