# Curated 中文、英文与日文字体实施记录

2026-09-25，用户确认将字体对比原型中的方向应用到正式界面：中文使用 HarmonyOS Sans SC，英文使用 Noto Sans，日语使用 Noto Sans JP。

## 设计框架

| 项目 | 决定 |
| --- | --- |
| 产品面与任务 | 全应用共享排版；保持资料浏览、详情、播放和设置的现有信息层级，仅更换字形。 |
| 既有实现 | 沿用 `src/style.css` 的全局字体令牌和现有 `html lang` 切换；不在各组件分散指定字体。 |
| 层级与密度 | 字号、字重、行高和间距维持现状；`Curated` 英文字标改用 Noto Sans。 |
| 状态 | 资源本地打包，离线可用；下载中使用系统字体回退；缺字形时继续回退。中日共用汉字的字形依据当前界面语言选择。 |
| 系统影响 | 更新全局字体栈、萃取帧水印字型、离线资源检查及“关于”署名；不改变业务数据或 API。 |

## 字体资源与许可

- HarmonyOS Sans SC 使用 Huawei 发布包中的未修改 Regular、Medium、Bold 原始 TTF，避免因字形裁剪或格式转换触及许可的“不得修改”条款。按需请求对应字重；本机已安装时优先使用本机文件。原始许可文件随资源保留，“关于”页展示字体署名及许可入口。
- Noto Sans 与 Noto Sans JP 使用 Fontsource 的本地资源包，并随应用保留各自的 OFL 许可。拉丁字母优先使用 Noto Sans；日语界面优先使用 Noto Sans JP 的日文字形；中文界面优先使用 HarmonyOS Sans SC 的汉字。英文界面的 CJK 文本优先使用 Noto Sans JP。外部元数据可能包含与当前界面语言不同的 CJK 文本，此时按当前语言的字体顺序回退。
- 原型 `2026-09-24-font-comparison.html` 保留，作为选择前的比较记录。它使用的日文字体子集仅服务原型，正式界面使用完整的 Fontsource 日文字形资源。

## 关于页的开源项目使用许可

“关于”页以独立的“开源项目使用许可”卡片列出 Curated 的 MIT 许可，以及 HarmonyOS Sans SC、Noto Sans、Noto Sans JP 的字体许可。列表只显示名称、简短署名或许可类型，完整条款通过各自的本地文件打开；鸿蒙字体条目明确说明本软件使用该字体并保留 Huawei 署名。原先分散在项目信息与字体提示中的许可内容合并到此处。
