# 播放列表（Player Playlist）需求整理

日期：2026-08-17  
状态：第一期已开始落地  
窗口：当前片前后各 10 部，边缘再预取 4 部  
收起标签：热区悬停才显示；标签更窄，使用 `bg-background`  
来源：口语需求整理 + 边界确认

## 一句话定义

播放列表不是独立片单实体，而是：**从资料库或演员页进入播放器时**（可以直接进，也可以先开详情再进），才把那份有序列表变成连续播放队列。播放器可在片尾自动接下一部，也支持手动上一首 / 下一首；右侧用可展开面板展示当前附近的滑动窗口。

书签（Saved Views）继续只负责保存资料库筛选。应用书签后从资料库点进播放器，队列自然就是那份筛选结果。

## 已拍板决策

| 问题 | 决定 |
| --- | --- |
| 哪些入口有队列 | 只有两个浏览入口：资料库、演员页。详情页是中间站，不单独决定有没有队列 |
| 首页 / 历史 / 萃取帧进入 | 无队列，无右侧列表，无自动接下一部 |
| 资料库或演员页先开详情再播放 | 有队列，跟随进入详情前的那份列表 |
| 资料库或演员页双击卡片 | 直进播放器，有队列；单击仍进详情 |
| 当前片不在队列里 | 无右侧列表，也没有上一首 / 下一首 / 片尾自动前进 |
| 长列表渲染 | 不渲染完整列表；只渲染当前附近，并随滚动做滑动窗口 |
| 自动接下一部时如何起播 | 续播该片已有进度；没有进度，或进度已达/接近片尾（≥95%）则从头 |
| 最后一部播完 | 停住，不循环 |
| 自动接下一部 | 允许开关 |
| 手动切换 | 同时提供上一首 / 下一首 |

## 与现有能力的关系

| 现有能力 | 当前事实 | 播放列表要补的缺口 |
| --- | --- | --- |
| 资料库筛选 / 书签 | 已能得到一份有序海报网格 | 从资料库点进播放器后，这份网格还没有变成队列 |
| 演员页 | 已按该演员过滤出影片网格 | 从演员页点进播放器后，还没有把这份列表当成队列 |
| 进入播放器 | 资料库走 `browse`；演员页走 `back=actor`；`?autoplay=1` 只表示立刻开播当前这部 | `autoplay` 不会在片尾切到下一部 |
| 片尾行为 | `PlayerPage` 的 `ended` 只停止当前片 | 有队列且开关开启时，应自动进下一部 |
| 观看历史卡片 | 宽版横向卡：文字在左、海报在右 | 播放列表卡片要类似形态，但图文左右对调 |

第一期仍然不新建可随意增删改的播放列表实体。

## 产品原则

1. **队列跟浏览入口走，不跟最后一跳走。** 资料库 / 演员页可以直接进播放器，也可以先开详情再进；这两种都有队列。首页、历史、萃取帧即使路由还带着 `browse`，也没有队列。
2. **有队列的浏览入口只有两个：资料库、演员页。** 详情页本身不是入口，只是资料库 / 演员页路径上的中间站。
3. **当前片必须属于该队列，右侧面板才出现。** 不属于则当作普通单片播放。
4. **顺序等于入口网格的阅读顺序。** 先行后列，从左到右，再从上到下。
5. **播放器仍然视频优先。** 右侧面板默认收起；列表只渲染当前附近的滑动窗口。

## 范围

### 第一期要做

1. 从资料库进入：以当前资料库可见列表为队列（含默认列表、筛选、书签；含资料库 → 详情 → 播放器，以及双击卡片直进播放器）
2. 从演员页进入：以该演员页影片网格为队列（含演员页 → 详情 → 播放器，以及双击卡片直进播放器）
3. 片尾自动接下一部（可开关；接下一部时续播已有进度，接近片尾则从头）
4. 手动上一首 / 下一首
5. 播放器右侧可展开面板，滑动窗口展示当前附近条目
6. 左图右文的宽版横向卡片

### 第一期不做

- 独立的自定义播放列表实体
- 拖拽重排
- 随机播放
- 循环播放
- 把书签改名为播放列表
- 为首页、历史、萃取帧等入口补队列

## 1. 队列来源

### 1.1 有队列

**资料库 → 播放器**（含资料库 → 详情 → 播放器）

- 无筛选、无书签：队列 = 当前资料库默认列表，排序 = 当前网格排序
- 有筛选或已应用书签：队列 = 该结果集，排序 = 该视图当时的网格排序
- 常见路径是点海报先进详情，再从详情点播放；队列仍是进入详情前的资料库列表，不是详情页自己的列表
- 双击资料库影片卡会跳过详情，直接进播放器，队列同样是当前网格

**演员页 → 播放器**（含演员页 → 详情 → 播放器）

- 队列 = 该演员详情页正在展示的影片
- 顺序 = 演员页网格的阅读顺序
- 双击演员页影片卡同样直进播放器，队列不变

### 1.2 无队列

以下入口进入播放器后，按单片播放处理：

- 首页（含首页 → 详情 → 播放器；首页双击卡片直进播放器也无队列）
- 观看历史
- 其他未点名入口（如萃取帧）默认同样无队列

详情页本身不决定队列。只有当详情是从首页这类无队列入口进来时，再点播放才按单片处理。

无队列时：

- 不出现右侧标签和面板
- 不提供上一首 / 下一首
- 片尾停住，不自动前进

### 1.3 当前片不在队列里

即使入口本应有队列，只要当前播放的影片不在该队列中：

- 不出现右侧列表
- 不提供上一首 / 下一首
- 片尾停住

## 2. 自动播放与手动切换

这里的「自动播放」有两层，必须分开：

| 含义 | 现状 | 第一期目标 |
| --- | --- | --- |
| 进入播放器后立刻开播当前片 | 已有，由 `?autoplay=1` 驱动 | 保持不变 |
| 当前片播完后自动接下一部 | 没有 | 仅在有队列、当前片属于队列、且开关开启时新增 |

### 2.1 片尾自动前进

前提：存在有效队列，当前片在队列中，且「自动接下一部」为开。

1. 当前影片播放到结尾。
2. 若存在下一部：进入下一部。
3. 下一部若已有观看进度且尚未接近片尾（<95%），则从该进度续播；没有进度，或进度已达/接近片尾（≥95%），则从头开始。
4. 对已看完或接近看完的片子再次点播放（含从资料库/详情进入当前这部）时，同样从头播放，不要因为立刻 `ended` 而跳到下一部。
5. 若已是队列最后一部：停住，不循环。
6. 右侧面板若已展开，当前项切到新影片，滑动窗口随之移动。

开关关闭时，片尾行为与现在相同：停在当前片。

### 2.2 手动上一首 / 下一首

仅在有效队列存在时提供。

- 下一首：切到队列中的下一部；若已是最后一部，则不可用。
- 上一首：切到队列中的上一部；若已是第一部，则不可用。
- 手动切换同样续播目标片已有进度；目标片已接近片尾时从头开始。
- 按钮放在现有播放/暂停工具栏：`上一首 · 快退 · 播放 · 快进 · 下一首`。内层切进度，外层切队列。无队列时不渲染外层两键。

### 2.3 工作假设

- 有队列时，「自动接下一部」默认开启。
- 开关放在播放器内，具体控件位置实施方案再定。

## 3. 右侧面板

位置：播放器画面右侧。  
默认：收起。  
出现条件：存在有效队列，且当前片属于该队列。

### 3.1 触发

‹ 标签**默认不显示**。展开后，同一枚标签留在抽屉左缘，用来收回。

1. 热区是播放器**画面区域**的右缘一条窄带（不含底栏音量 / 设置那一侧）。
2. 只有鼠标进入这块热区时，才显示带向左箭头的标签。
3. 热区包含标签本身，避免鼠标从热区移到标签上时闪藏。
4. 鼠标离开热区后，标签立刻隐藏。
5. 点击标签后，列表以抽屉形式盖在整个播放器之上；画面、进度条和底栏宽度不变。
6. 展开后，标签留在抽屉左缘并改为向右箭头；再点一次即收回。
7. 点击抽屉以外的空闲区域（含画面和底栏空位）也会收回。Escape 同样收回。
8. 没有有效队列时，热区和标签都不存在。
9. 标签显示与底栏沉浸式自动隐藏无关：即使底栏已隐藏，移到右缘仍应能看到标签。

### 3.2 展开内容

第一期用可上下滚动的列表，而不是轮盘。

- 清楚标出当前正在播放的影片
- 点击卡片切到该片，并续播其已有进度
- 面板是盖在整个播放器之上的右侧抽屉，不是挤占布局的兄弟列

### 3.3 展开时的布局

列表展开后，播放器表面保持单列全宽；抽屉叠在上层：

```
[ 画面 + 顶栏 + 进度条 + 底栏  （宽度不变） ]
                    [ 播放列表抽屉 ]
```

- 播放器画幅、进度条、萃取帧标记都不因列表开关而变窄或重排
- 抽屉宽度约 `min(28rem, 46%)`，比第一版更宽，好放下横版海报
- 底栏保持现有两列网格：左五键组，右音量 / 设置 / 画中画 / 全屏
- 收起时的 `‹` 标签默认隐藏，只在鼠标进入画面右缘热区时出现
- 用半透明遮罩承接「点空白收回」，不要把列表做成会推动布局的第二列

### 3.4 滑动窗口

资料库可能很长，面板**不得**一次性渲染完整队列。

- 初始只渲染当前播放项附近的一段
- 用户向上 / 向下滚动时，窗口沿队列滑动并补齐附近项
- 窗口之外的条目不进入 DOM

窗口具体长度实施方案再定；产品约束是「当前附近 + 随滚动滑动」，不是全量列表。

```
队列（逻辑上完整，但不全部渲染）

  ... 未渲染 ...
  ┌────────────────┐  ← 滑动窗口
  │  上一首附近     │
  │  当前播放  ●    │
  │  下一首附近     │
  └────────────────┘
  ... 未渲染 ...
```

## 4. 列表排序

播放列表从上到下 = 入口网格的阅读顺序：

```
网格：                      播放列表：

  [1] [2] [3] [4]             1
  [5] [6] [7] [8]             2
                              ...
                              8
```

先行后列，从左到右，再从上到下。播放列表不另做一套排序。

资料库队列跟随当时的筛选 + `sort`。  
演员页队列跟随该页网格当时的展示顺序。

## 5. 卡片样式

参考观看历史卡的横版海报裁切，图文对调后贴齐卡片边缘：

```
观看历史（现状）：            播放列表（目标）：

  [ 标题 / 演员 / 番号 ] [图]    [图] [ 标题 ]
                                 [    番号 ]
                                 [    演员 ]
```

1. 海报靠左，使用与观看历史相同的横版比（`2.25/1`，宽屏 `2.4/1`），贴齐卡片左/上/下边缘，不再四周留白。
2. 标题、番号、演员在右侧，左对齐并紧贴海报右缘。
3. 当前播放项要有可见选中态。

## 6. 当前实现锚点

以下是现有代码事实，不是实施方案。

- 资料库可见列表：`LibraryView.visibleMovies` = 筛选结果 + 当前 `sort`
- 资料库直进播放器：`buildPlayerRouteFromBrowseIntent(..., back: "browse")`；影片卡双击走同一条路径
- 资料库经详情进播放器：同一套 browse query，但 `back: "detail"`；队列跟随 `browse`，返回仍回详情
- 首页经详情进播放器：`back: "detail"` 且 `detailBack: "home"`；无队列
- 演员页影片：`ActorDetailPage.actorMovies` 按演员名过滤全库缓存，再交给 `VirtualMovieMasonry`
- 演员页进播放器：`buildPlayerRouteFromActorIntent()`，带 `back=actor`
- 历史进播放器：`buildPlayerRouteFromHistory()`，无资料库网格上下文
- 片尾：`PlayerPage.onVideoEnded()` 目前只停止当前片
- 续播：现有 `getResumeSecondsForOpenPlayer()` 已会把进度写进 `?t=`
- 历史卡布局：`PlaybackHistoryCard.vue` 现为文左图右
- 底栏：`sm:grid-cols-[minmax(0,1fr)_minmax(0,1fr)]`，左播放键、右音量/设置/PiP/全屏
- 萃取帧标记：`PlayerProgressFrameMarkers` 对进度条根节点做 `ResizeObserver`，按像素宽度重新分簇

## 7. 仍待实施方案细化的细节

这些不再改变产品方向，只影响怎么做：

1. 「自动接下一部」开关的具体位置（画板默认建议列表标题栏），以及记住到下次打开软件。
2. 抽屉遮罩浓度与收回手势是否要支持把列表边缘再拖回去；当前先用点空白 / 再点标签 / Escape。

已拍板：进度 ≥95% 视为接近片尾，与现有续播/完成判定一致。再次打开或切到这样的片子时从头播放；自然看完整部后仍自动接下一部。开播后极短时间（<2s）就 ended 时，先从头重播一次，避免连环跳过。

## 8. 第一期验收口径

1. 从资料库点进播放器（无筛选也一样，含先开详情再播放，以及双击卡片直进）：有队列；播完自动进网格阅读顺序中的下一部，并续播其进度；下一部若已接近片尾则从头播。已看完的当前片再次点播放时从头播，不会立刻跳到下一部。
2. 从演员页点进播放器（含先开详情再播放，以及双击卡片直进）：队列为该演员页影片；行为同上。
3. 从首页、历史点进播放器（含首页先开详情再播放）：无右侧列表，无上一首 / 下一首，片尾停住。
4. 当前片不属于队列：表现与无队列相同。
5. 最后一部播完后停住。
6. 「自动接下一部」可关闭；关闭后片尾停住，但手动上一首 / 下一首仍可用。
7. 鼠标移到画面右缘热区才出现向左箭头标签；离开热区即隐藏。点击后以抽屉盖在播放器之上，画幅和进度条不变。
8. 列表卡片为左图右文；横版海报贴齐卡片边缘，文字左对齐并紧贴海报。
9. 面板不渲染完整长列表。
10. 点击空白处、再次点击标签或按 Escape 可收回列表。
11. 列表展开后底栏右列仍是音量 / 设置 / 画中画 / 全屏，不掉到播放键下方。
