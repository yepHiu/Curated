# AI 整理入口、标签复用与任务历史

用户需求：优先复用已存在的标签，减少同义/近义重复，允许必要的新题材；单片右键与详情更多、批量选择提供 AI 整理；进度在侧栏独立呈现，保留设置；任务历史采用窄行列表，展示时间、影片数量与状态。

## 实施

- 移除上一轮保留的 160 个累计题材上限，保留单响应有界和上下文分页，确保影片库扩展不会停止新增题材。
- 用户标签与既有题材进入复用候选目录，按使用量优先；同名/已记录别名直接复用，新提议再经分页语义对照。兼容的同义或近义提议复用已有规范名，保留实质不同的题材，不执行全库破坏性标签合并。
- 仅修改任务范围的用户标签，继续验证原文证据、人工修订、保留/排除、NFO 只读与撤销。
- 共用选择范围预览与启动流程：单片、已选影片、全库；已有活动任务时查看状态，不重复提交。selected API 仍为 1–600，前端明确显示并阻止超限。
- 侧栏播放区域附近增加整理入口与进度条，折叠态保留可访问入口，移动抽屉使用同一组件；移除遮住设置的 fixed 按钮。
- 整理面板顶部显示当前任务与范围，其下最多 50 条持久任务采用限高列表，每行时间/影片数/状态，展开后提供结果、停止、重试和撤销。
- 中/英/日文同步。复用现有服务层与 UI primitives，不新增接口或配置。

## 验证

- 后端：累计题材超过 160、已有用户标签复用、跨页同义匹配、新题材保留、无效映射拒绝、旧中断恢复/长输入回归。
- 前端：选择 ID 固定快照与范围确认、避免空选/超限/重复提交、三处入口、状态入口不覆盖设置、紧凑历史与展开操作、Web/Mock 范围一致。
- 日常 typecheck/lint、相关 Vitest、后端 test/vet 与生产构建；按现有显示清单检查窄屏/桌面和折叠布局，完整 display 测试仍遵循单独授权规定。
