# Desktop 空白处重新加载

桌面主界面与连接页在空白处右键提供单项“重新加载”，执行当前窗口的 `window.location.reload()`，保留当前 URL；网页端不启用。该操作会重建页面内存状态，未保存的页面编辑按普通刷新处理。

复用现有 shadcn-vue DropdownMenu 的鼠标坐标锚点、语义颜色、焦点与关闭机制，不新增布局容器或设计令牌。输入框、可编辑区域、按钮、链接、媒体、已选文字和已有业务右键菜单优先，不显示刷新菜单。支持视口避让、Esc、点击外部、滚动和窗口失焦关闭。独立原生播放器窗口不接入。

全局监听随组件卸载清理，主界面仅检测到 Electron bridge 后挂载；连接页使用自身 bridge。验证覆盖桌面/网页差异、区域排除、业务菜单优先、刷新动作和关闭行为，并执行类型检查与局部 lint。

## 实施与验证

已接入 `App.vue` 与 `ConnectionPage.vue`，文案支持中文、英文、日文。组件使用无布局节点的 DropdownMenu 与虚拟鼠标坐标锚点；原有业务 ContextMenu 和已阻止默认行为的事件不被接管。

- 相关 3 个测试文件共 24 项通过，含主页面错误兜底、Web 不挂载、区域排除、动作与关闭及卸载清理。
- 局部 ESLint、`pnpm typecheck`、`pnpm build` 与 `pnpm build:desktop-ui` 通过。前端构建报告首屏 JS 相对人工基线的 raw/gzip 两项增长提醒，未超过阻断上限。
- 未进行真实 Electron 窗口人工验收或发布安装包。主页面需运行新 Server 前端（或开发前端），连接页需更新 Desktop 本地页面。
