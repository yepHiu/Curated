# 导入前番号检查

日期：2026-08-23

## 问题

「添加影片」选完文件后直接上传。文件名包装不同（站点前缀、`-C`、分片后缀）时，库里已经有同一番号的影片仍会被再导入一份。

## 方案

仍是同一个导入对话框。选完文件后自动调用 `POST /api/import/movies/code-check`；已有相同或类似番号的文件在列表旁显示「影片已导入，请勿重复导入」。底部仍是原来的「开始导入」，不另开审查步骤。

解析规则与扫描共用 `scanner.ExtractNumber`。匹配：

- **exact**：规范化后相同，或去掉连字符后相同（`SSIS-001` / `SSIS001`）
- **similar**：连字符分段前缀（`SSIS-001` / `SSIS-001-CD1`）
- 不把 `ABC-12` 当成 `ABC-123`

提示不阻断导入；用户可用行内移除按钮去掉该文件。检查失败保持静默，不挡住主流程。
