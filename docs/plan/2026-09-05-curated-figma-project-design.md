# Curated 已实现 UI → Figma 原生设计稿

## 目标与纠正记录

用户要求将已实现的 Curated UI 转为真正可编辑的 Figma UI 原稿。此前导入结果使用整页截图裁切充当媒体，用户明确否决了这种交付。用户同意保留参考截图，不等于接受截图拼装作为原稿。

2026-09-05 至 2026-09-06 已在原文件中进行原生重建：重新组装首页、资料库、手机卡片，替换所有截图裁切媒体，整理 Auto Layout、主组件及实例，修正导航、设置菜单、开关和图标。没有修改应用业务代码。

## 原生结构与素材

- MovieCard 桌面主组件 `3:2880`；手机主组件 `3:8961`。Code、Title、Actor、Rating、Tag 1–4 为 TEXT 属性，Show rating 为 BOOLEAN 属性；Poster 为独立 IMAGE 填充；遮罩为原生渐变。卡片、信息区和标签行使用 Auto Layout。
- HomeHero 主组件 `3:8655`：完整原始封面、原生渐变、独立编号和标题、查看详情与立即播放按钮。首页用实例组成轮播轨道。
- AppSidebar 导航变体集 `3:5770`；AppHeader `3:3144`；LibraryToolbar `3:3170`。
- SettingsNav `3:9269` 含 11 个分区状态；Switch `3:9276` 含 Off、On、Disabled。12 个设置导航与 12 个开关实例已替换。
- 重复控件建立本地主组件，图标通过 INSTANCE_SWAP 属性替换，避免不同标签共用错误图标。主组件与文字继续使用现有主题变量。
- 旧组件库 7 处、页面 73 处截图媒体已换成独立图片。媒体来自资料库原图文件、数据库保存的萃取帧和应用已使用的演员头像资源；图片按设计尺寸缩放。萃取帧页额外核对顺序并替换为实际的 20 张独立画面。
- 旧首页 `1:11801` 与旧资料库 `1:494` 已由新原生画板替换。旧说明 `1:15000` 已由新目录替换，以上旧链接不再使用。

31 张画板：01 首页；02 全部影片；03 演员库；04 个人洞察；05 萃取帧；06 观看历史；07 设置概览；08 影片详情；09 演员详情；10 回收站；11 收藏；12 播放目标未找到；13 锁定；14 页面未找到；15 通用设置；16 元数据刮削；17 播放设置；18 影片存储；19 萃取帧设置；20 维护；21 关于；22 安全；23 网络；24 实验性功能；25 Agent 新对话；26 浅色资料库；27 导入影片对话框；28 手机资料库；29 手机导航抽屉；30 手机设置；31 首页内容区。

这些是可以编辑原生图层的设计画板，不代表全部路由交互、动态内容与浏览器状态都已完成 Figma 原型连线。长页面仍以此前选定的视口为范围，不包含全部滚动内容。播放器仅保留播放目标未找到状态，没有启动播放。首页轮播使用重建时的实际数据样本，轮播的动态内容可能与旧参考截图不同。

原稿中的媒体图片为正常独立素材；图片文件自身印刷的文案仍属于图片内容。UI 的标题、编号、评分与按钮为独立原生图层。部分复杂 CSS 效果、字体度量及固定尺寸布局与浏览器仍有视觉差异；不是全页面自适应行为的无损转换。
