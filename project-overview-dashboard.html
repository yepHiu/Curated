运行与体验

当前技术形态

  • 前端：Vue 3 + TypeScript + Vite，shadcn-vue 与 Tailwind CSS v4；Mock 与 Web API 适配器并存。
  • 后端：Go HTTP 服务运行在 SQLite 之上；开发态默认 loopback :8080。
  • 桌面：Electron MVP 已具备后端启动/复用、托盘、隐藏到托盘、静态 Web UI 与目录选择桥接。
  • 播放：浏览器直放 + FFmpeg/HLS；同片多会话互不抢占，新流就绪后交接，HLS 错误有界恢复，显式起点与取消贯穿请求链。

尚未全绿

发布门禁与完整验收

  • 构建体积：总 JS 为 2374.43 kB raw / 780.54 kB gzip，超过 2250 / 750 kB 门禁；修复前基线也超限，预算未放宽。
  • 浏览器 e2e：最新默认超时的串行运行 3 通过 / 2 失败：移动端旧元素定位、个人洞察冷启动超时。后者仅延长超时的诊断运行通过。
  • Agent R1：演员别名、完整源站结果、多轮候选交互、三语言及移动端焦点 / 取消验收仍有缺口；用量治理和回执保留期管理未完成。
  • 播放边界：真实影片画质、LAN / GPU 基准和完整浏览器媒体验收待补；Go race 受本机工具链阻塞。缓存字节配额、按需 VOD、音频单独转码尚未实现。
