运行与体验

当前技术形态

  • 前端：Vue 3 + TypeScript + Vite，shadcn-vue 与 Tailwind CSS v4；Mock 与 Web API 适配器并存。
  • 后端：Go HTTP 服务运行在 SQLite 之上；开发态默认 loopback :8080。
  • 桌面：Electron MVP 已具备后端启动/复用、托盘、隐藏到托盘、静态 Web UI 与目录选择桥接。
  • 播放：浏览器直放 + FFmpeg/HLS；同片多会话互不抢占，新流就绪后交接，HLS 错误有界恢复，显式起点与取消贯穿请求链。
