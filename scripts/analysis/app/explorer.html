从整个项目，到一个函数。把散落的文件、累积的体量和交织的依赖，放回同一张地图。

这些数字如何计算？查看范围、算法和边界
  • 范围：当前 jav-shadcn 仓库，Git 已跟踪文件 + 未忽略的新文件，读取生成时磁盘上的内容。包含工作区修改；不包含相邻 Android / 插件仓库。默认排除依赖、vendor、构建产物、运行数据及报告自身。
  • 体量：物理行数包含空行与注释，Vue 包含 template / script / style；非空行仍包含注释。字节数来自文件内容，二进制不计算行数。不是安装包大小，也不是整个硬盘占用。
  • 分类：测试目录与 .test / .spec / _test / test_ 命名归为测试；docs 与文档扩展名归为文档；声明文件 .d.ts 归为配置。实现源码包含脚本、SQL、CSS 和原生 C/C++。按路径分类，不代表每个文件都由项目原创。
  • 函数：TypeScript 编译器解析 JS/TS，Vue SFC 解析器提取 script，Go 使用 go/parser。包含有函数体的声明、方法、访问器及匿名回调；不含类型签名。Vue 模板表达式、Python、C/C++、Shell 等只统计文件，未做函数分析。函数长度是起止行跨度，嵌套函数的跨度会重叠，不能求和当作总行数。
  • 分支指标：每函数基数 1，加 if、循环、非 default case、catch、三元条件及 && / || / ??；Go 还计非 default select 分支。跳过嵌套函数内部。不是严格 CFG 圈复杂度，也不包含 optional chaining 等所有语义路径。不同语言的分数仅作阅读线索，长函数或高分不直接表示缺陷。
  • 依赖：JS/TS 的静态 import / export、字面量 dynamic import / require；支持 @/ 和相对路径。Go 的项目内 import 按包统计，包含平台专用文件，未应用 build tags。线条是跨模块导入引用数，不是函数调用数、HTTP / IPC 调用链或运行时频次。外部包不进入关系图；同模块依赖保留在文件详情。
  • 图表与排行受当前范围及搜索影响，顶部四个总览数字始终表示整个快照。地图点击目录下钻，点击文件查看细节；极小方块可从下方目录列表访问。
