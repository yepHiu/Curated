# Inno Setup language resources

`ChineseSimplified.isl` is vendored from the Inno Setup **is-6_7_1** tag:
https://github.com/jrsoftware/issrc/blob/is-6_7_1/Files/Languages/Unofficial/ChineseSimplified.isl

Translator attribution remains in the file. Inno Setup permits use and distribution
of its language files; see https://github.com/jrsoftware/issrc/blob/is-6_7_1/license.txt.
Keeping the translation in the repository makes builds independent of optional
language files installed on the build host and avoids network access at compile time.
